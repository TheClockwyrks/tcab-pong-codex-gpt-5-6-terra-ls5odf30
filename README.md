# Carom

Carom is a top-down paddle duel with a little extra curve. Send the ball through
the central pylons, move your paddle through each hit to add spin, and be the
first side to reach 11 points with a two-point lead.

## Run it

Install dependencies with `npm ci`, then start the development server with
`npm run dev`. Build the self-contained static site with `npm run build`; the
result is written to `dist/` and can be served from any static web server.

## Controls

- Player one / Solo: `W` and `S`
- Player two in Versus: Up and Down arrows
- Menus: `W`/`S` or arrow keys, then `Enter` or `Space`
- Pause: `P` or `Escape`
- Mute: `M`

The menus also work with a mouse or touch.
